This is a script to check the Cloud SQL On Demand Backup size in your GCP Projects.
2 parameters can be used to run the script:
1. -i  : Name of the Cloud SQL instance (Required)
2. -p  : The Project ID Google Cloud (Optional)

After download, make sure to change the file mode to execute by running: chmod +x script.sh.
You can download the sh file [here] (https://github.com/indragmx/csql-tools/blob/main/check_csql_backup_size.sh).
